Model & API notes

Intervals use integer minutes on an abstract horizon [0, 525600], with start included and end excluded. A booking ending at minute 60 leaves capacity available for one beginning at 60. This app deliberately does not interpret time zones or calendar dates.

SQLite serializes capacity checks and inserts in one write transaction. Cancellation requires the current booking version. Previews are advisory; the final reservation always checks again. Rejected requests do not consume their request key. Accepted keys remain bound to their payload even after cancellation.

Local-only demonstration: there is no authentication, payment, automatic expiry or background scheduler. Keep the server on loopback. Up to 100 resources, 500 bookings per resource and 10,000 bookings overall, including cancelled history.
